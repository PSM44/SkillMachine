# AA.CONSTITUTION — IT Project Delivery Constitution

## Purpose

This folder contains the constitutional operating model for AI-assisted IT project delivery inside SkillMachine.

The constitution exists to accelerate real outputs:

- `DEPLOY_DONE`: executable/deployable product output.
- `DELIVERABLE_DONE`: analytical, documentary, operational, or non-deployable product output.

## Files

- `01.CONSTITUTION.HUMAN.md`: human-readable version with diagrams, rationale, and examples.
- `02.CONSTITUTION.AI.txt`: AI-oriented operational contract.
- `03.OPERATING_CARD.HUMAN.md`: short human checklist for sessions.
- `04.OPERATING_CARD.AI.txt`: compact machine-oriented execution gate.

## Key rule

This constitution exists to accelerate `DEPLOY_DONE` or `DELIVERABLE_DONE`.

If applying the constitution delays the first functional output unnecessarily, it is being used incorrectly.
