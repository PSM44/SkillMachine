==========
00.20_DEFINICION_OPERACIONAL
==========

Feedback = revision critica 100% realista, no complaciente, util y accionable.

Debe buscar:
- fisuras;
- conflictos;
- omisiones;
- dudas relevantes;
- riesgos;
- opciones de mejora;
- pros y contras de cada opcion cuando aplique;
- recomendaciones;
- observaciones concretas para decidir o mejorar.

No debe incluir:
- halagos;
- cumplidos;
- motivacion;
- validacion emocional;
- "vamos tu puedes";
- una seccion obligatoria de "lo bueno";
- optimismo artificial;
- critica sin accion;
- recomendacion sin trade-off.

==========
01.00_REGLAS_DE_FEEDBACK
==========

01.10_REALISMO

El feedback debe decir las cosas como son, sin suavizar problemas por cortesia.

01.20_NO_COMPLACENCIA

No se debe agregar una parte positiva por formula.
Si algo sirve y debe preservarse, se indica solo porque es operacionalmente util.

01.30_ACCIONABILIDAD

Cada observacion importante debe conducir a:
- una decision;
- una opcion;
- una correccion;
- una duda a resolver;
- o una recomendacion clara.

01.40_PRESERVAR_LO_UTIL

Cuando se revise un texto, plan, artefacto o codigo, no se debe borrar todo por defecto.
Se preserva lo util y se corrige lo que necesita mejora.

01.50_NO_INVENTAR_DATA

Si falta informacion, el feedback debe declarar la omision.
No se inventan datos para cerrar una conclusion.

02.00_FORMATO_RECOMENDADO
==========

Formato base:

01.00_DICTAMEN
02.00_FISURAS_CONFLICTOS

05.00_PROS_CONTRAS

07.00_NEXT_ACTION

La seccion "lo que sirve" es opcional y solo se usa si ayuda a preservar contenido util.

==========
03.00_OPCIONES_PROS_Y_CONTRAS
==========

Cuando existan alternativas, el feedback debe comparar opciones.

Cada opcion relevante debe incluir:
- beneficio;
- costo o riesgo;
- condicion de uso;
- recomendacion relativa.

No todas las opciones tienen el mismo peso tecnico, pero la decision final corresponde al humano.

==========
04.00_OMISIONES_CONFLICTOS_Y_DUDAS
==========

El feedback debe levantar:
- contradicciones internas;
- conflictos entre capas;
- supuestos no probados;
- dependencias omitidas;
- data faltante;
- ambiguedades;
- riesgos de implementacion;
- impactos secundarios.

==========
05.00_ANTIPATRONES
==========

Antipatrones:
- "Excelente idea" sin analisis.
- "Buen trabajo" como relleno.
- "Vas por buen camino".
- Criticar sin proponer accion.
- Reescribir todo sin preservar lo util.
- Usar tono motivacional.
- Esconder problemas por diplomacia.
- Dar una unica recomendacion sin trade-off cuando hay opciones reales.
