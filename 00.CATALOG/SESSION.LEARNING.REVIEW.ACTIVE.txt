==========
01.00_OBJETIVO
==========

El modulo SESSION_LEARNING_REVIEW se ejecuta como parte conceptual de SESSION_CLOSE.

Su funcion es revisar lo ocurrido en la sesion y detectar:
- reglas repetidas por el humano;
- correcciones recurrentes;
- fricciones operativas;
- gaps de contexto;
- oportunidades de Skill;
- oportunidades de GRC;
- posibles patches a artefactos existentes;
- conflictos entre artefactos;
- deuda tecnica emergente.

==========
02.00_CONTRATO_DURO
==========

Este modulo solo produce candidatos y recomendaciones.

No puede:
- crear Skills automaticamente;
- crear GRC automaticamente;
- modificar canon sin aprobacion humana;
- borrar artefactos;
- fusionar artefactos;
- marcar deprecated sin revision.

Toda mejora debe ir primero a backlog o a una minibattle explicita.

==========
04.00_CRITERIOS_DE_DETECCION
==========

Detectar candidatos si aparece cualquiera de estas senales:
- el humano corrige la misma regla mas de una vez;
- la IA pregunta algo que deberia estar en un artefacto;
- aparece una convencion operacional recurrente;
- se crea un workaround que deberia ser proceso;
- una carpeta output necesita regla de uso;
- un script necesita contrato;
- un warning se repite;
- un concepto aparece como termino de arte;
- hay conflicto entre Skills/GRC/Usecases.

==========
05.00_INTEGRACION_CON_SESSION_CLOSE
==========

SESSION_CLOSE debe incluir una etapa final opcional:

SESSION_LEARNING_REVIEW:
- revisar sesion activa;
- detectar candidatos;
- clasificar prioridad;
- actualizar backlog si procede;
- proponer minibattle siguiente;
- no modificar canon salvo instruccion explicita.

==========
06.00_ANTIPATRONES
==========

- Crear microSkills por cada conversacion.
- Convertir cada preferencia de estilo en Skill.
- Actualizar canon durante una sesion sin cierre.
- Usar aprendizaje de sesion para justificar cambios no revisados.
- Cerrar sin backlog cuando se detecto oportunidad real.
- Mezclar feedback critico con halago o motivacion.

   Falta de HUMAN, falta de Context Composer, prompt usecase incompleto,
   mal uso de output generado, o ejecución técnica prematura.

   HUMAN, 00.CATALOG, SkillsLake, GRCLake, usecase prompt source, registry, BUILD,

   Registrar candidato o proponer minibattle explícita.

   Confirmar que no se crea ni modifica canon sin instrucción humana o minibattle aprobada.
