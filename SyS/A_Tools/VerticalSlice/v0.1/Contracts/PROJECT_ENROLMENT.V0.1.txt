Enrolment = permission to exchange governed SkillsMachine information/packages.
Enrolment ≠ autonomous permission for SkillsMachine to mutate the project.

DISCOVERED
NOT_ENROLLED
ENROLMENT_PENDING
ENROLLED
SUSPENDED_OR_DISCONNECTED

IMPROVEMENT_FLOW_ENABLED

LAST_OBSERVED_AT

SKILLSMACHINE_PACKAGE_EXCHANGE_ONLY

NEW_PROJECT_ENROLMENT=
1. Create project identity
2. Establish 00_SKILLSMACHINE surface proposal
3. Human approval
4. Register ENROLLED + capability baseline
5. Enable Improvement Flow / Project Sync flags as approved

EXISTING_PROJECT_ENROLMENT=
1. Read-only discovery
2. Capability inventory
3. Local-vs-canonical comparison
4. Conflict/fork detection
5. Enrolment proposal
6. Human approval
7. Baseline establishment
8. Status=ENROLLED

DISCONNECT_OR_SUSPEND=
Human-authorized; sets SUSPENDED_OR_DISCONNECTED; stops new deliveries; preserves history

ELIGIBILITY_FOR_PROJECT_SYNC_APPLY=
CREATED_BY_SKILLSMACHINE=true
OR
(EXPLICITLY_ENROLLED_IN_SKILLSMACHINE=true AND ENROLMENT_STATUS=ENROLLED)

NON_GOALS=
No machine-specific secrets in registry
No silent enrolment
No CloseReport-specific exception path
No SkillsMachine authority to mutate project functional code without project-local approval

CLOSEREPORT_CLASS_AT_076A2=EXISTING_UNINTEGRATED_PROJECT
CLOSEREPORT_ENROLMENT_STATUS_AT_076A2=NOT_ENROLLED
