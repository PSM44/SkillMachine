MODEL=delivery contract (not uncontrolled file mirroring)

REQUIRED_FIELDS=
PACKAGE_ID
TARGET_PROJECT
CAPABILITY_ID
FROM_VERSION
TO_VERSION
DEPENDENCIES
COMPATIBILITY
PREFLIGHT
REVERSIBILITY
HUMAN_APPROVAL
DELIVERY_STATUS

ELIGIBILITY=
TARGET must satisfy:
CREATED_BY_SKILLSMACHINE
OR
EXPLICITLY_ENROLLED_IN_SKILLSMACHINE with ENROLMENT_STATUS=ENROLLED
No project-specific exception paths (including CloseReport)

AUTHORITY_SPLIT=
SkillsMachine: publish package, deliver to governed surface, track desired state
Target project: authorize and execute local apply; validate; emit update receipt

PREFLIGHT_MINIMUM=
identity gate; eligibility; clean worktree (updater); compatibility; reversible plan; human approval for apply

DELIVERY_STATUS=
PREPARED
DELIVERED
AWAITING_PROJECT_APPROVAL
REJECTED
SUPERSEDED

TARGET_APPLY_STATUS=
NOT_STARTED
APPLYING
APPLIED
FAILED
ROLLED_BACK

DESIRED_VS_OBSERVED=
CANONICAL_CAPABILITY_VERSION
PROJECT_OBSERVED_CAPABILITY_VERSION
PROJECT_SYNC_STATUS
LAST_DELIVERY_ID
LAST_UPDATE_RECEIPT_ID

REVERSIBILITY=required for updater-managed paths; project-local executors must declare rollback or refuse apply

UPDATE_RECEIPT_CONSUMPTION=
SkillsMachine records a target-emitted update receipt via Register-ProjectSyncTargetReturnReceipt / Action=ConsumeTargetReturnReceipt.
This does not mutate the target project.
DELIVERY_STATUS PREPARED becomes DELIVERED when a valid target apply receipt is acknowledged.
TARGET_APPLY_STATUS uses contract values (NOT_STARTED|APPLYING|APPLIED|FAILED|ROLLED_BACK).
Richer target-side evidence may be stored in TARGET_APPLY_EVIDENCE without replacing the contract enum.
PROJECT_SYNC_APPLIED on a delivery record means SkillsMachine applied into the target; it remains NO for this module.
ORIGINAL_DELIVERY_STATUS and ORIGINAL_TARGET_APPLY_STATUS preserve the prepared snapshot.
Idempotent replay of the same UPDATE_RECEIPT_ID + TARGET_HEAD is allowed.
Wrong delivery, wrong project, mismatched HEAD, or a second distinct receipt is rejected.
