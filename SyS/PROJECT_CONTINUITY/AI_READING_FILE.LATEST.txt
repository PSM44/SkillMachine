==========

          Stage only explicitly named files.

          The pre-commit hook (Validate-System.ps1) is a hard gate.

          Only cherry-pick / selective promotion with human decision.

          USECASE.REGISTRY.json, BUILD.ps1, and manifests have semantic field constraints.

          Always run git status --short first. If not clean: stop, diagnose, fix.

RULE_06: No heredoc Bash syntax inside PowerShell (no cat <<EOF, no $(cat <<...)).
          Use PowerShell here-strings: @'...'@ for literal, @"..."@ for interpolated.

          Write long scripts to a .ps1 file first, then execute with a short launcher.
          Gate: pwsh.exe [System.Management.Automation.Language.Parser]::ParseFile(...)

RULE_08: Validate before every commit.
          Command: pwsh.exe -NoProfile -ExecutionPolicy Bypass -File "SyS\A_Tools\Validation\Validate-System.ps1"
          Required exit code: 0.

RULE_09: No push to main.
          Push only to current lab branch unless human explicitly approves main push.

RULE_10: No structural changes to registries/manifests without schema-aware patching.
          USECASE.REGISTRY.json bundle_definitions source_files must use full repo-relative paths.
