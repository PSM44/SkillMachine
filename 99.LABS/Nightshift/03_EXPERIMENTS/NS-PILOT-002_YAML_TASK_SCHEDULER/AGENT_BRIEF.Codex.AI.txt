05.00 WHAT TO BUILD
==========

Files to create inside src/:
  src/__init__.py        (empty or minimal)
  src/parser.py          read YAML, return task list, raise errors for missing file / invalid YAML
  src/scheduler.py       filter by status, sort by priority or due_date
  src/report.py          format task list as plain text report
  src/cli.py             argparse CLI: --input, --filter-status, --sort-by, --output

Files to create inside tests/:
  tests/__init__.py      (empty)
  tests/test_parser.py
  tests/test_scheduler.py
  tests/test_report.py
  tests/test_cli.py

Exact CLI interface:
  python -m src.cli --input PATH [--filter-status STR] [--sort-by FIELD] [--output PATH]

Exit codes (mandatory, exact):
  0 = success
  1 = input file not found
  2 = invalid YAML

Priority sort order: high → medium → low
Due date sort order: ascending (earliest first)
