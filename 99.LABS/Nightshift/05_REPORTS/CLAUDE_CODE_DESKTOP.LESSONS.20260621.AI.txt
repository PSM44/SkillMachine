==========
04.00 RULES LEARNED
==========
RULE_01_ENVIRONMENT_GATE:
Claude Code Desktop must start with a hard environment gate: root, branch, HEAD, main HEAD, and clean tree.

RULE_02_AGENT_BRANCH:
Agent execution must happen on a dedicated agent branch created from a verified clean base.

RULE_03_NO_AGENT_WORK_ON_BASE:
Agents must not implement directly on lab/ns-pilot-001-hybrid, main, or any shared base branch.

RULE_04_PR_DISCIPLINE:
Do not create PR automatically from the UI. A PR requires explicit base branch, compare branch, draft/review purpose, and no-merge status.

RULE_05_WORKING_TREE_PROOF:
Do not state WORKING_TREE=CLEAN unless git status --short returns empty.

RULE_06_PYTHON_CLEANUP:
After Python tests, remove __pycache__ and verify git status before evidence and commit.

RULE_07_EVIDENCE_HASH_SEMANTICS:
Evidence must not rely on a single COMMIT_HASH field when evidence may be corrected later.
Use IMPLEMENTATION_COMMIT, EVIDENCE_FIX_COMMIT, and BRANCH_HEAD.

RULE_08_NO_PR_BEFORE_COMPARISON:
Agent branches are evidence branches. Do not merge or promote before comparison/scoring.

RULE_09_NO_MAIN_PUSH:
Agent branches must not push to main.

RULE_10_SCORE_IS_NOT_SELF-AUTHORITATIVE:
Agent self-estimated score is not final. It must be reviewed during comparison.

==========
05.00 RECOMMENDED PROTOCOL
==========
1. Verify base branch and clean working tree.
2. Create dedicated agent branch.
3. Read only spec, agent brief, sample input, evidence template, and rubric notes.
4. Implement only allowed files.
5. Run tests and smoke tests.
6. Remove generated runtime artifacts.
7. Verify git status.
8. Create evidence with IMPLEMENTATION_COMMIT / EVIDENCE_FIX_COMMIT / BRANCH_HEAD semantics.
9. Validate repository.
10. Stage explicitly.
11. Commit and push only the agent branch.
12. Do not create PR until comparison/scoring.
