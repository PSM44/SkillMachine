03.00 ALCANCE
==========

TASK SELECCIONADO: NS-PILOT-002_YAML_TASK_SCHEDULER

Descripción:
Construir un CLI Python que lea un archivo YAML con tareas (tasks) y produzca
un reporte de texto formateado con filtrado y ordenamiento.

Especificación funcional mínima:

  Inputs:
  - Archivo YAML con lista de tareas.
  - Cada tarea tiene: title (str), priority (high/medium/low), due_date (YYYY-MM-DD), status (open/done/blocked).
  - Flags CLI:
      --input PATH          archivo YAML de entrada (obligatorio)
      --filter-status STR   filtrar por status (opcional)
      --sort-by FIELD       ordenar por priority o due_date (opcional, default: priority)
      --output PATH         archivo de salida (opcional, default: stdout)

  Outputs:
  - Reporte de texto con tasks listadas en orden especificado.
  - Línea de resumen al final: total tasks, open, done, blocked.
  - Si el archivo de entrada no existe: error con exit code 1 y mensaje claro.
  - Si el YAML es inválido: error con exit code 2 y mensaje claro.

Estructura de código esperada:
  src/
    parser.py       — leer y validar YAML
    scheduler.py    — filtrado y ordenamiento
    report.py       — formateado de salida
    cli.py          — entry point CLI
  tests/
    test_parser.py
    test_scheduler.py
    test_report.py
    test_cli.py

Criterio cuantitativo mínimo: >= 12 tests pasando.
