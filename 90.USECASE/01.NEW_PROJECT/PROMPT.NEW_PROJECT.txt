PROYECTO: New Project Bootstrap

OBJETIVO:
Crear el set mínimo correcto para iniciar un proyecto nuevo de cualquier índole.

INPUT:
- requerimiento del usuario
- SKILL.MENU
- skills adjuntos
- policies de bootstrap, lifecycle, artifacts, WhoAmI
- standards base de BATON, HUMAN y RADAR

DEBES:
1. evaluar si el set adjunto es suficiente
2. pedir skills adicionales si faltan
3. crear propuesta para:
   - WhoAmI
   - BATON
   - HUMAN
4. definir siguiente acción
5. mantener consistencia con policies y standards

OUTPUT:
- evaluación de suficiencia del set
- skills faltantes
- propuesta de artefactos iniciales
- siguiente acción recomendada





==========
MB-GRC-026I_USECASE_FOLDER_UPLOAD_PACKAGE
==========

REGLA:
La carpeta del usecase es el paquete operativo de subida a la IA.

CARPETA_A_SUBIR:
C:\01. GitHub\Skills\90.USECASE\01.NEW_PROJECT

REGLAS:
- Subir el contenido completo de la carpeta del usecase correspondiente.
- No usar Temp\TO_UPLOAD_TO_IA.
- No pedir el repo completo por defecto.
- Si falta contexto, pedir paths exactos adicionales desde SkillsLake, GRCLake, 00.CATALOG, SyS u otra ruta necesaria.
- Si se detecta oportunidad de crear o mejorar Skill/GRC, registrarla como candidato; no crear canon automáticamente.


==========
MB-GRC-027C_PROMPT_ENGINEERING_DISCOVERY_CHALLENGE
==========

REGLA:
Cuando el nuevo proyecto requiera crear, auditar o perfeccionar prompts, la IA debe aplicar 30.SKILL.PROMPT_ENGINEERING_DISCOVERY_CHALLENGE.txt.

La IA debe:
- ejecutar discovery antes de generar prompts finales;
- desafiar alcance, inputs, outputs, restricciones y criterios de éxito;
- declarar PROMPT_READY antes de generar un prompt final;
- usar DRAFT_NOT_READY si falta información relevante;
- mantener la capa pedagógica subordinada a la respuesta operacional.

La IA no debe:
- generar prompts finales sobre requerimientos incompletos;
- crear canon automáticamente;
- convertir una respuesta operacional simple en una clase.
