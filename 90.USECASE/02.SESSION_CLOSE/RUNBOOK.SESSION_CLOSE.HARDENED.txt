01.00_PROPOSITO
==========

Este runbook existe para evitar cierres de sesión incompletos.

Problema que resuelve:
- Cierres sin Git status.
- Cierres sin HEAD/tag.
- Cierres sin validación.
- Cierres sin evidencia RADAR.
- Cierres sin chequeo BATON/WHOAMI.
- Dependencia excesiva de memoria humana.

==========
04.00_CRITERIO_DE_CIERRE
==========

OK:
- Git limpio.
- Validate-System.ps1 OK.
- RADAR manifest existe.
- BATON existe.
- WHOAMI existe.

WARN:
- Validación OK, pero Git tiene cambios pendientes.

FAIL:
- Validación falla.
- Falta RADAR manifest.
- Falta BATON.
- Falta WHOAMI.

==========
05.00_REGLA_OPERATIVA
==========

Si el resultado es OK:
- Se puede cerrar sesión.

Si el resultado es WARN:
- Revisar cambios Git antes de cerrar.

Si el resultado es FAIL:
- No cerrar como sesión limpia.
