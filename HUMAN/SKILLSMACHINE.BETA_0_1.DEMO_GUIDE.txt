## 01. Purpose

This guide defines the current demonstrable SkillsMachine beta slice.

The goal is to show a real operator workflow that can be executed from one visible entrypoint without requiring the user to inspect the repository manually.

## 02. Main Entry Point

Run from repository root:

pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action help

## 03. Current Demo Flow

Recommended 5-minute demo sequence:

1. Show available commands.

   pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action help

2. Show repository and artifact status.

   pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action status

3. Show RADAR status without regenerating RADAR.

   pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action radar-status

4. Validate the canonical session-continuation upload package.

   pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action package-upload

5. Validate usecase build readiness without executing mutating build.

   pwsh -File SyS\A_Tools\Launcher\Start-SkillsMachine.ps1 -Action build-usecase

## 04. What This Demo Proves

This demo proves that SkillsMachine now has:

- a single visible operator entrypoint;
- safe read-only status actions;
- a canonical upload package discovery action;
- a safe build-usecase readiness action;
- documented execution commands;
- AI_TAIL-compatible execution protocol for future scripts.

## 05. What This Demo Does Not Yet Prove

This is not yet full Beta 0.1 because the following are still pending:

- final session-close after current branch work;
- merge / PR readiness decision;
- management-ready summary artifact;
- optional execution test of build-usecase -RunBuild in a controlled branch;
- final confirmation that a non-technical target user can run the flow without assistance.
